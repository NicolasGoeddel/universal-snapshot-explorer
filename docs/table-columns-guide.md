# Table Columns User Guide (Quick Reference)

**Universal Snapshot Explorer** allows you to completely customize your table layouts. Your adjustments are saved automatically per view (Explorer, Details, Roots) and scale perfectly across different screen sizes.

### Quick Reference Shortcuts

| Action | How to do it | What it does |
| :--- | :--- | :--- |
| **Resize a Column** | Drag the invisible border on the right edge of any column header. | Resizes the column smoothly. Adjacent columns automatically compress ("Accordion Physics") to keep the table in bounds without cutting off text unnecessarily. |
| **Intelligent Auto-Fit** | Double-click the border on the right edge of any column header. | Perfectly fits all undersized columns to their visible text (e.g. long dates or file sizes) while preserving any columns you manually made wider. Extra space is automatically given to the `Name` column for maximum filename readability. |
| **Sort by Column** | Click anywhere on the text of the column header. | Toggles sorting for that specific column (ascending/descending). |
| **Reset to Default** | Clear your browser's local storage for the site. | Restores the default layout proportions. |

> [!NOTE]
> Some special utility columns like the **Checkbox** column (`32px`) and the **Actions** column (`60px`) are fixed. They cannot be resized and will never stretch or compress.
